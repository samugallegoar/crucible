PROFILE FORMAT. exchange_fees_v1 drops participant_type for classification_dimension + classification_value, adds a required unit (per_contract_per_side only) and the other-only charge_name/applies_quote/distinct_from. ParticipantProfile is an immutable sorted tuple of (dimension, value): dimensions ^[a-z][a-z0-9_]*$, values non-empty, "unknown" allowed and means unknown, "none"/"all" for a same-for-everyone row; canonical SHA-256 of sorted JSON. load_participant_profile reads a flat YAML mapping. CLI --participant-profile FILE replaces --fee-participant-type; MCP is participant_profile: object (written to a temp YAML; only the content hash is recorded). Recorded in the manifest, summary.json (mapping + sha) and every attempts.parquet row (participant_profile_sha256), and in the evaluation-id basis, so two profiles are two artifacts. Required only when a component is excluded.
RESOLUTION. Take rows covering (root, date, component), then per row: none/all applies; a dimension missing or "unknown" makes the component a gap "classification <dim> not declared"; a different value makes the row inapplicable; exactly one applicable row prices it, two raise (ambiguous), none is a gap "no fee row ... matches the declared classification". No default, no fallback. The NFA pass-through is gone: that row is nfa_assessment_eligibility=fcm_member, so a profile that omits it gaps. fee_rows_as_of returns FeeLookup{priced, gaps with reasons}; ComponentFeeSource.rows_for became lookup(profile=...). "other" is the one summing exception.
OTHER RULES. Required on an other row (refused when missing/empty): charge_name (generic refused case-insensitively after punctuation strip: other/others/misc/miscellaneous/fees/other fees/cme other fees/additional fees/charges and word-only variants with cme/exchange/fee(s)); unit exactly per_contract_per_side (monthly/platform/subscription/account refused, message points to the ruleset fee schedule); source_url on www.cmegroup.com; quote; applies_quote; distinct_from; root; effective_from; classification (or none/all when the source says it is the same for all). covers must be exactly other; any other fee_type listing other is refused ("an exchange fee cannot cover other components"); exchange may still cover exchange;clearing. Two same-name+root+classification overlapping other rows are refused; different names on one date are summed. Assumption entries now require unit: per_contract_per_side, and an entry covering other requires a charge_name (same refusal list).
